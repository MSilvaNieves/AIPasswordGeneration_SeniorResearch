# AIPasswordGeneration_SeniorResearch

AI Password Generation using Kimi K3 and a PII-Augmented PCFG framework.

# Objective

The objective of this project is to see how well AI-assisted password cracking is at guessing a password using Personal Identifiable Information. This project uses Kimi K3 for the AI and also uses a PII-Augmented PCFG Framework as the baseline.
